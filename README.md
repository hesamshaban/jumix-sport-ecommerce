# 🏀 Jamix Sport

A modern sports e-commerce website focused on **volleyball and basketball footwear and sports products**.

Jamix Sport is a front-end project built from scratch with **HTML, CSS, and Vanilla JavaScript**, with an emphasis on dynamic product rendering, filtering, shopping interactions, reusable components, and a structured multi-page experience.

🔗 **Live Website:** https://jumixsport.ir
🔗 **GitHub Repository:** https://github.com/hesamshaban/jumix-sport-ecommerce

---

## 🧠 Architecture & Development

The project was developed with **Vanilla JavaScript**, without using a frontend framework such as React.

JavaScript functionality is separated into different modules responsible for specific parts of the application, including:

* Product management
* Product rendering
* Cart management
* Wishlist management
* Product filtering and sorting
* Pagination
* Header rendering
* Footer rendering
* Article rendering

The application also uses **ES Modules** to keep JavaScript functionality organized and maintainable.

## 🎯 Product Categories

The website is designed around sports products, with a particular focus on:

* 🏐 Volleyball
* 🏀 Basketball
* 👟 Training & lifestyle products

The home page provides category-based navigation and dynamically loads featured products.

---

## 💾 Data & State Management

The project uses browser-side technologies to manage application data and user interactions.

`localStorage` is used for persistent client-side data such as:

* Shopping cart
* Favorite products

Product and article data are handled on the client side and rendered dynamically through JavaScript modules.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/hesamshaban/jumix-sport-ecommerce.git
```

Navigate to the project:

```bash
cd jumix-sport-ecommerce
```

Then open `index.html` in your browser.

For the best development experience, use a local development server such as **VS Code Live Server**.
